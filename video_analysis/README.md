# ローカル動画解析 MVP

試合MP4からイニング切り替わり**候補**を探し、画面で確認・訂正する独立モジュールです。動画本体はPC内で読み取り専用として扱い、クラウドには送信しません。`fee-collector/` やInstagram制作とは接続していません。リポジトリには現時点で共通のTeam OSチャット画面がないため、MVPの入口はローカルのデスクトップ画面です。

## 起動

WindowsでPython（Tkinter、OpenCV、NumPy）とFFmpeg/FFprobeを使用できる状態にしてください。`start-video-analysis.cmd` をダブルクリックすると画面が開きます。開かない場合は、`py -3 -m video_analysis.app` でエラーを確認できます。

1. 「動画を選択」からローカルMP4を選び、「解析する」を押します。
2. 粗解析は全体を10秒間隔・幅640pxで読み、持続的な色の状態変化から候補を選びます。
3. 候補の前後45秒を1秒間隔で再解析し、候補時刻を絞ります。
4. 候補を選択し、正解または不正解と、必要なら正しい時刻・理由を保存します。後日「保存済み結果を開く」から再確認できます。

表示スコアは**正解確率ではありません**。紫・緑・黄色の比率に持続的な変化があるかを比べるための暫定値です。単発の色変化やフレーム差分だけでは採用しません。人物検出やプレー状態認識はまだなく、カメラ移動・背景色・ベンチ映像による誤検出、または見逃しがありえます。候補は必ず映像で確認してください。

解析結果はリポジトリ内の無視対象 `.local/video-analysis/` にJSONとして保存します。元動画の絶対パス、容量、解析日時、設定、ロジックバージョン、候補時刻・スコア、正誤、修正時刻、理由を記録します。解析ごとに新しいJSONを作り、以前の結果と元動画は上書きしません。別PCへの自動同期はありません。実動画や解析結果をGitへ追加しないでください。

## 今回の検証と次の課題

既存の `GX010430_analysis.csv`（10秒間隔340件）を読み込み、粗解析で 11:00、25:00、34:50、39:40、43:20 を候補として出しました。これは映像との正誤照合ではありません。開発環境のPATHにはユーザー環境で導入済みとされた `py`・`ffmpeg` が見つからず、実MP4からの抽出と画面操作は未検証です。次は当該PCで実動画の全工程を実行し、正解・不正解を保存してからしきい値を調整します。分割、打席検出、チャット操作は次フェーズです。
