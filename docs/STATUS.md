# Status entry point

This file is the fixed cross-PC status entry point.

## Canonical handoff

The authoritative current implementation handoff is:

- `docs/PROGRESS.md`

Read it before implementation and update it before ending a meaningful Codex session.

## Required handoff fields

The handoff must include:

- active branch;
- completed work;
- next task;
- verification performed;
- blockers / external dependencies.

Do not duplicate the full progress history here.
